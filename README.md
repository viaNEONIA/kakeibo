# 簡易家計簿 PWA

ブラウザーで使う、オフライン対応の家計簿です。収入・支出・返金、予算、独立した繰越プール、目標、定期収支を管理し、家族の端末間でJSONファイルを交換できます。

[アプリを開く](https://vianeonia.github.io/kakeibo/) · [実機試験リスト](docs/TEST_CHECKLIST.md) · [文書一覧](docs/INDEX.md)

## できること

- 5画面：ホーム・予算・入力・一覧・設定。専用テンキー、連続登録、直前取消、検索・編集・削除。
- 収入/支出項目の追加・並び替え・無効化、基本予算・項目別振分、前期間の予算だけの手動コピー。
- 独立プールの配分・取消・調整、手動締め・差額再精算、負残高/未精算額と期間別推移。
- 適用期間別の目標設定・変更・解除、達成率・不足額・履歴、目標設定ごとの初回達成表示。
- 毎月の定期収入・支出、月末日補正、予定月からの手動確定。予定は実績に含めません。
- 収支CSV・プール期間別CSV、全量JSONバックアップ/復元、オフライン起動・保存。
- 親1台と子端末のJSON手動統合、親優先/子登録順の競合解決、子の予算仮表示。

収入と予算は独立しています。プール配分は収入や支出として登録しません。負残高の未精算額を別途二重控除せず、後期間の余剰で解消します。

## 最初の操作

1. 設定で収入・支出の項目を追加します。
2. 予算で日付から集計期間を用意し、基本予算・項目別振分を保存します。プールの初期残高は利用前に設定します。利用後の変更は調整で行います。
3. 入力から収入・支出・返金を登録し、一覧で確認します。期間末は予算から手動で締めます。
4. 必要に応じて予算で目標、設定で定期収支を設定します。定期予定は設定画面で手動確定します。
5. 復元用JSONを端末外にも保存します。CSVは集計用で、復元・統合には使いません。

## ファイルの用途

| 保存名の先頭 | 用途 | 読込先 |
| --- | --- | --- |
| `kakeibo-復元用バックアップ-` | 保存時点へ全量復元 | 設定 → バックアップと復元 |
| `kakeibo-家族統合用-` | 同一家計簿の変更を統合 | 設定 → 家族で共有 → 統合用JSONを取り込む |
| `kakeibo-子参加用-` | 親が登録した新しい子1台の初回参加 | 設定 → 家族で共有 → 子として初回参加 |
| `kakeibo-収支-` / `kakeibo-プール期間別-` | 集計用CSV | Excel等。アプリ内への読込不可 |

読込確認の用途・作成元・日時・家計簿IDと実行する操作を確認します。保存リンクは作成時点の内容です。変更・統合後は元の保存ボタンで作り直してください。
自動保存が始まらなければ「JSONを保存」または「CSVを保存」を直接押します。アプリ内共有が使えない場合は保存先のファイルアプリから共有できます。保存済みなら再保存不要です。[保存の詳細](docs/FILE_SAVE.md)

## 家族共有と復旧

親が子ごとに別の参加ファイルを発行します。子の変更を親へ取り込み、親で作成し直した統合結果を子へ戻します。親が取り込んだだけでは子は更新されません。
通常復元は統合と異なり全量上書きです。共有中は同一家計簿に限定し、子の端末IDを保持します。初期状態への親復旧には専用の確認条件があります。稼働中の親の引継ぎとは異なります。
[共有の権限・手順](docs/FAMILY_SHARING.md) · [子の仮表示](docs/CHILD_BUDGET_PREVIEW.md) · [親バックアップ復旧](docs/PARENT_RECOVERY.md)

## 起動と開発確認

静的HTML/CSS/JSのためビルド不要です。通常利用に本番パッケージや外部CDNは不要です。

```bash
npm ci
npm test
npm run serve
```

ローカル起動先は http://localhost:4173/ 。ブラウザー自動試験はPlaywrightのChromiumが必要です。

```bash
npx playwright install chromium
npm run test:browser
npm run test:browser:recurring
```

既存Chromiumは `CHROMIUM_PATH=/path/to/chromium` で指定できます。コマンド一覧と旧版更新試験の基点は[自動試験記録](docs/TEST_RESULTS_CURRENT.md)を参照。スマートフォンのPWA・オフライン機能はHTTPSで確認します。

## 制限・未実装

クラウド自動同期、稼働中の親の権限移譲、子の解除/再登録、定期周期の拡張、目標達成予定月の推定は未実装です。期間設定の変更は保存済み最後の期間の締め後に行います。
設定のデータ一括削除・入力設定や、旧計画のグラフ記載など、仕様と実装の要確認点は[未確定・差分一覧](docs/OPEN_QUESTIONS.md)で管理します。アプリ内共有やOS側のインストール判定をアプリだけで保証しません。インストール対策としてサイトデータ削除は要求しません。
