# 繰越計算の決定記録 — 2026-10-19

根拠: ユーザーが収入と予算、繰越原資、未使用配分、予算超過、月締め、過去修正、残高不足、初期残高の推奨案に「ok」と回答。予算超過には「プール超過時は警告を出し超過分を保留しては？」という追加提案あり。続いて「負残高を未精算額として併記し、後月の余剰で解消する保留方式でokです」と明示承認（2026-10-19 22:39 JST）。

## 承認済み

- 収入登録で予算を自動増額しない。
- 利用可能予算＝基本予算B＋当月プール配分A。
- 月末精算額S＝B＋A−当月支出E。月全体の総額で計算し、正負両方を対象にする。
- 未使用配分はSに含めてプールへ戻す。別途の全額戻し・取消と重ねて戻さない。
- 予算超過はSを負としてプールから減額する。
- 自動で見込み計算、手動で月締め確定。再確定は前回反映額との差額だけを反映する。
- 過去修正時は後続月を再計算し、配分・調整履歴を保持する。
- 負残高と警告を表示し、不足中の新規配分を停止する。
- 初期プール残高は開始時に入力可能、初期値0円。

## 算術定義

月初プールP、調整Jの場合、月末実残高N＝P−A＋S＋J。
したがってN＝P＋B−E＋J。配分Aは予算へ移して未使用分を戻すため、二重に消費されない。
月別表示は追加max(S,0)、超過精算max(-S,0)、配分A、調整J、実残高Nを区別する。超過精算と配分は収入・支出に追加計上しない。

## 承認済み方式の受入数値

P=30,000、B=100,000、A=20,000、J=0。

| 支出E | 精算S | 月末実残高N |
| --- | --- | --- |
| 90,000 | 30,000 | 40,000 |
| 110,000 | 10,000 | 20,000 |
| 120,000 | 0 | 10,000 |
| 130,000 | -10,000 | 0 |
| 140,000 | -20,000 | -10,000 |

同一月を同条件で再確定しても残高は変わらない。Eを110,000から125,000へ修正した場合、Sは10,000→-5,000、差額は-15,000、Nは20,000→5,000。翌月配分15,000の直後、他の増減なしなら-10,000となり、履歴保持・警告・新規配分停止を確認する。

## Q-HOLD — 保留額の具体的な扱い（承認済み）

プール不足分を無視せず、以下の表示として保留する。

- 実残高Nは符号付きで保持する。
- 配分可能額＝max(N,0)。
- 未精算額＝max(-N,0)。実残高から導出し、別の支出や追加控除として記録しない。
- 後の正の精算・調整でNが回復すると未精算額も減る。正の調整を新規収入と自動的に同一視しない。
- 未精算額0までは新規配分を停止する。既存取引・配分履歴は削除しない。

例: N=-10,000なら「実残高-10,000／配分可能0／未精算10,000」。後の精算+6,000でN=-4,000、未精算4,000。さらに+7,000でN=3,000、未精算0、配分可能3,000。過去の超過分10,000をこの時点で再度差し引かない。

負残高を保持し、未精算額を併記して後月の余剰で解消する方式を正式採用。未精算額は実残高の導出値であり、二重の債務・支出として記録しない。月別推移は各月の実残高から当時の未精算額を導出する。

## 集計期間設定への適用 — 2026-10-19

家計簿の集計期間・締め日を設定可能とする方針が承認された。上記の「月初/月末/当月/後月」は設定された集計期間の開始/終了/当期/後期へ対応し、同じ計算式を適用する。期間境界・ラベル・既存履歴の移行はOPERATIONS_DECISIONのP-Q01/P-Q02で承認済み。現在期間の締め後から変更し、過去の確定期間は維持、端数移行期間の予算は手動設定。期間変更を理由に配分や精算を重複計上しない。
