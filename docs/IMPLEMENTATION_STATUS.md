# 実装状態 — 0.4.4-dev / 家族共有・親復旧

正式仕様v1.3と承認済み追補を基準にI04基盤、I05収支入力・項目管理・収支一覧、I06予算・繰越と家族共有を実装。家計簿全体は開発途中です。

## 実装済み

- ビルド不要、外部CDN・本番パッケージなし。PWA、17ストアIndexedDB版2。旧版1から非破壊移行。JSONは未共有形式1/共有形式2。
- ホーム/予算/入力/一覧/設定の5画面ナビ。予算画面から予算・プール・精算を操作。
- 支出・収入・返金、日付、任意名称/メモ、専用テンキー（7/8/9上段、0/00/削除/クリア）、独立登録。
- 設定順6項目＋「その他」、連続登録（種類・日付・項目を保持、金額・名称・メモをクリア）、直前取消。
- 項目追加/名称変更/並び替え/無効化・再有効化。履歴のある項目を物理削除せず参照保持。
- 1件1行一覧、期間/収支/項目/金額帯/名称・メモ/定期収支の絞り込み、列表示と並び順の保存。
- 行タップで編集・確認後削除、日付移動時に期間所属を更新。締め済み期間の支出変更は差額精算と監査履歴を同時保存。
- 返金は返金日の純支出を減らす。収入は予算へ自動加算しない。ホームの収入・純支出・収支を表示。
- 同額連続登録と再試行の重複を区別。古い更新版/復元世代での保存を拒否し下書きを維持。
- 旧I04バックアップ互換、全量復元、オフライン登録、明示的なPWA更新と保存済みデータ保持。

- 基本予算・項目別振分・前期間コピー、プール手動配分/取消/調整/初期残高、月締め/差額再確定・監査履歴。
- ホーム予算警告、独立残高/未精算額/配分可能額、3/6/12/全期間推移、開始日変更と移行期間接続。

## 未実装と制限
