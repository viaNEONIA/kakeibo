# 実装状態 — 0.1.0-dev / I04

2026-10-19のユーザー「実装開始」を根拠に、I04の基盤を実装。まだ完成した家計簿ではありません。

## 実装済み

- ビルド不要の静的HTML/CSS/ES Modules。外部CDN・本番依存パッケージなし。
- Manifest、PNGアイコン、Service Workerのアプリシェルキャッシュ。リポジトリ配下のサブパスに対応。
- 17ストア・複合主キー・一意索引を持つIndexedDB版1。初期プール0円。
- 設定保存と再起動後の保持（注意閾値を基盤確認用UIから保存可能）。
- 操作IDの冪等性、revision競合、複数タブの直列化、復元後の旧世代書込拒否。
- 一貫した読取から全17ストアをJSONバックアップ。
- 形式版・型・日付・金額・キー重複・参照先・期間連続性・精算一致・監査履歴の検証後、確認ダイアログを経て全量復元。
- 全量置換は一つの保存境界で実行。途中失敗でclear/putが部分反映されないことを試験。
- 更新は待機し、利用者の明示操作後のみ適用。入力中の自動リロードなし。
- DB版更新要求時は接続を閉じ、編集を停止して再起動を案内。DB削除での復旧は禁止。

## 実行と再検証

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run serve
```

通常起動: http://localhost:4173/ 。スマートフォンで使う配信先はHTTPSが必要。GitHub Pagesならリポジトリ直下の静的ファイルをそのまま配信できる構成ですが、ホスティング設定・公開操作は今回していません。
ブラウザ試験は組込のローカルHTTPサーバーを起動し /kakeibo/ サブパスで実行。既存Chromiumを使う場合はCHROMIUM_PATHで実行ファイルを指定可能。スクリーンショットは既定で一時領域へ出し、リポジトリへ実データや画面を追加しません。

## I04の残る受入確認

Android Chrome実機、iPhone Safari（ホーム画面追加含む）、PC Chrome/Edgeでの手動確認は未実施。Chromiumの狭幅試験を実機試験と同一視しません。WebKit試験も未実施。Issue #4はこれらの確認を残して開いたままにする。
DB版1から将来版への移行コードはまだなく、将来版追加時に明示的な変換と非破壊移行試験が必要。今あるデータを消して新規DBを作る処理は実装していません。
Service Worker資産を変更するときはsw.jsのVERSIONを更新して全キャッシュを入れ替えます。新しい資産キャッシュ作成に失敗した場合は既存キャッシュを維持します。
