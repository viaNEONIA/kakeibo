インストールは現在成功確認あり・再発監視中。過去の再発があるため恒久解決とはしません。ファイル取り違えによる未反映報告は統合不具合として扱わず、用途識別を改善済みです。アプリ内JSON共有の失敗は未解決/環境制限として残り、保存先からの共有を案内します。

## 実装上の制限

- 集計期間変更は保存済み最後の期間の締め後。既存未来期間の再分割は未対応。
- 定期リンク取引の種類・日付は固定。削除済み定期枠の専用再確定は未実装。
- 共有の管理操作（項目/予算/プール/期間/目標/定期/子登録）は親へ集約。月締め以外の細かな権限は実装上の選択として扱います。
- クラウド、アカウント認証/ファイル署名、稼働中親の移譲、子解除/再登録等は未実装。
- 設定の一括データ削除・入力設定の詳細UI、旧試験計画のグラフ記載には未実装/未定義の差分があります。[OPEN_QUESTIONS](OPEN_QUESTIONS.md)で別管理します。
- 目標達成予定月の推定は将来実装。OSプッシュ通知やアプリ終了中の達成判定は行いません。
