# 実装状態 — 0.2.0-dev / I05

正式仕様v1.3と承認済み追補を基準にI04基盤、I05収支入力・項目管理・収支一覧を実装。家計簿全体は開発途中です。

## 実装済み

- ビルド不要、外部CDN・本番パッケージなし。PWA、17ストアIndexedDB版1、JSONバックアップ形式v1を継続。
- ホーム/予算/入力/一覧/設定の5画面ナビ。予算画面は未実装を明示した準備中表示。
- 支出・収入・返金、日付、任意名称/メモ、専用テンキー（7/8/9上段、0/00/削除/クリア）、独立登録。
- 設定順6項目＋「その他」、連続登録（種類・日付・項目を保持、金額・名称・メモをクリア）、直前取消。
- 項目追加/名称変更/並び替え/無効化・再有効化。履歴のある項目を物理削除せず参照保持。
- 1件1行一覧、期間/収支/項目/金額帯/名称・メモ/定期収支の絞り込み、列表示と並び順の保存。
- 行タップで編集・確認後削除、日付移動時に期間所属を更新。締め済み期間の支出変更は差額精算と監査履歴を同時保存。
- 返金は返金日の純支出を減らす。収入は予算へ自動加算しない。ホームの収入・純支出・収支を表示。
- 同額連続登録と再試行の重複を区別。古い更新版/復元世代での保存を拒否し下書きを維持。
- 旧I04バックアップ互換、全量復元、オフライン登録、明示的なPWA更新と保存済みデータ保持。

## 未実装と制限

I06予算・繰越のUI/配分/締め操作、集計期間変更UI、I07目標UI、I08定期収支設定/確定UI・CSVは後続。保存構造と復元検証は維持する。既存の締め済みデータ修正はサポートするが、新規締め操作はI06。
通常取引は種類・日付を編集可能。復元で入った定期リンク取引は現行検証の予定日/種類を維持し、その2項目は編集停止。名称/金額/項目/メモの編集・削除は可能。定期の再登録・日付変更ルールはI08で検討する。
目標達成予定月推定は将来実装。

## 実行と再検証

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run test:browser:i05
npm run test:upgrade
npm run serve
```

通常起動はhttp://localhost:4173/。各ブラウザ試験は組込HTTPサーバーで /kakeibo/ サブパスを検証。既存ブラウザはCHROMIUM_PATHで指定可能。upgrade試験には旧I04コミットが必要、詳細はTEST_RESULTS_I05参照。
スマートフォン配信はHTTPS。ホスティング設定を今回変更していない。アプリ資産更新時はsw.jsのVERSIONを更新し、利用者が明示更新してから新キャッシュへ切替。DB版とバックアップ形式版は1を維持し既存データを初期化しない。
