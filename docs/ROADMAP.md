# 開発ロードマップ

## 初期リリース対象
1. PWA基盤、IndexedDB、更新・バックアップ基盤。
2. 収入/支出の専用テンキー入力、連続登録、一覧・編集・削除。
3. 月別予算・項目別予算・ホーム警告。
4. 独立繰越プール、手動配分、月別推移、整合性処理。
5. 繰越プール目標額・達成率・不足額・履歴。
6. 定期支出の予定と手動確定、CSV/JSON、実機試験。

## 将来実装（初期リリース対象外）
- **目標達成予定月の推定**：過去の繰越増加ペース等から達成月を予測。計算方法、外れ値、負の推移、データ不足の扱いは未設計。

## 開発ルール
未確定事項を先に解消。各機能をIssue化し、受入条件・試験結果を添える。mainには検証済み変更のみマージ。
