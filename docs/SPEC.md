# 正式仕様 v1.3

## 1. 目的と基本構成
ブラウザ単体で動作する簡易家計簿PWA。Android/iOS/PC対応、オフライン利用、IndexedDBローカル保存。日常の収入・支出を素早く記録し、月別予算と繰越プールを把握する。分析はCSVをExcel等に取り込んで行う。画面はホーム、予算、入力、収支一覧、設定の5つ。

## 2. 確定事項
- 収入と支出の両方を管理する。
- 月初めに基本予算を設定し、支出項目別に振り分ける。
- 支出項目は自由に追加・編集・並び替えできる。収入項目と支出項目を区別する。
- 入力画面は片手操作優先、専用テンキー、連続登録可能。金額必須、名称・メモ任意。
- 収支一覧は1取引1行、フィルターと表示項目切替に対応する。
- 定期支出は予定を表示し、実績登録は手動確定する。予定は実績に含めない。
- 独立繰越プールを管理し、当月予算への配分は手動で行う。
- 繰越プールの月別推移（追加、配分、調整、残高）を表示する。
- 繰越プール目標額を設定し、達成率、不足額、達成通知を表示する。
- CSV出力でExcel集計、JSONバックアップで完全復元する。
- 目標達成予定月の推定は将来実装（現行スコープ外）。

## 3. 予算と収支の区別
収入合計と予算は別概念。収入記録を予算へ自動加算しない。予算使用率は当月支出÷利用可能予算。予算が0円の場合は除算せず「未予算支出」などを表示。

## 4. 繰越プール
当月基本予算と繰越プール残高を別管理する。プールから当月への配分は収支取引として計上しない。月別推移は前月残高＋月末精算額（正負あり）－当月配分＋調整。二重追加を禁止する。過去月の支出修正は以後の残高へ反映し、既存配分履歴を無断削除しない。残高不足時は負残高と警告を表示し、新規配分を停止する。月末精算額は基本予算＋プール配分－支出の総額とし、超過も減額精算する。未使用配分は精算額に含めて戻す。自動見込み計算・手動確定、再確定は差額反映。過去修正では後続月を再計算する。初期残高は入力可能、初期値0円。詳細と数値例は[CARRYOVER_DECISION](CARRYOVER_DECISION.md)参照。プール超過分は負残高を保持し、未精算額max(-実残高,0)と配分可能額max(実残高,0)を併記する。後月の余剰で不足を解消し、未精算額を別途二重控除しない。

## 5. 目標
繰越プール目標は単一目標。目標額は変更・解除可能。達成率＝残高÷目標額×100、残額＝max(0,目標額－残高)。目標未設定時は達成率非表示。変更履歴を保持し、月別推移には当時有効な目標額を表示。目標達成は資金拘束を意味しない。

## 6. 非機能要件
主要画面は原則スクロールなし。ただし小画面や文字拡大では必要なスクロールを許容。PWA更新時のデータ維持、オフライン動作、Android/iPhone実機検証を必須とする。端末間同期は初期版の対象外。

## 7. 注意
仕様v1.0〜v1.3の会話中の提案値（例：項目ボタン6件、定期収入も手動、予算超過振分禁止）は確定事項と混同しない。`OPEN_QUESTIONS.md`参照。
