# 正式仕様 v1.3

## 1. 目的と基本構成
ブラウザ単体で動作する簡易家計簿PWA。Android/iOS/PC対応、オフライン利用、IndexedDBローカル保存。日常の収入・支出を素早く記録し、月別予算と繰越プールを把握する。分析はCSVをExcel等に取り込んで行う。画面はホーム、予算、入力、収支一覧、設定の5つ。

## 2. 確定事項
- 収入と支出の両方を管理する。
- 集計期間の開始時に基本予算を設定し、支出項目別に振り分ける。
- 支出項目は自由に追加・編集・並び替えできる。収入項目と支出項目を区別する。
- 入力画面は片手操作優先、専用テンキー、連続登録可能。金額必須、名称・メモ任意。
- 収支一覧は1取引1行、フィルターと表示項目切替に対応する。
- 定期収入・支出は予定を表示し、実績登録は手動確定する。予定は実績に含めない。
- 独立繰越プールを管理し、当月予算への配分は手動で行う。
- 繰越プールの月別推移（追加、配分、調整、残高）を表示する。
- 繰越プール目標額を設定し、達成率、不足額、達成通知を表示する。
- CSV出力でExcel集計、JSONバックアップで完全復元する。
- 目標達成予定月の推定は将来実装（現行スコープ外）。

## 3. 予算と収支の区別
収入合計と予算は別概念。収入記録を予算へ自動加算しない。予算使用率は当月支出÷利用可能予算。予算が0円の場合は除算せず「未予算支出」などを表示。

## 4. 繰越プール
当月基本予算と繰越プール残高を別管理する。プールから当月への配分は収支取引として計上しない。月別推移は前月残高＋月末精算額（正負あり）－当月配分＋調整。二重追加を禁止する。過去月の支出修正は以後の残高へ反映し、既存配分履歴を無断削除しない。残高不足時は負残高と警告を表示し、新規配分を停止する。期間末精算額（月末精算額）は基本予算＋プール配分－支出の総額とし、超過も減額精算する。未使用配分は精算額に含めて戻す。自動見込み計算・手動確定、再確定は差額反映。過去修正では後続月を再計算する。初期残高は入力可能、初期値0円。詳細と数値例は[CARRYOVER_DECISION](CARRYOVER_DECISION.md)参照。プール超過分は負残高を保持し、未精算額max(-実残高,0)と配分可能額max(実残高,0)を併記する。後月の余剰で不足を解消し、未精算額を別途二重控除しない。

## 5. 目標
繰越プール目標は単一目標。目標額は変更・解除可能。達成率＝残高÷目標額×100、残額＝max(0,目標額－残高)。目標は1円以上、0円は保存不可、解除は別操作。目標未設定時は達成率非表示。変更履歴を保持し、月別推移には当時有効な目標額を表示。目標達成は資金拘束を意味しない。

## 6. 非機能要件
主要画面は原則スクロールなし。ただし小画面や文字拡大では必要なスクロールを許容。PWA更新時のデータ維持、オフライン動作、Android/iPhone実機検証を必須とする。端末間同期は初期版の対象外。

## 7. UI・運用の決定追補

[OPERATIONS_DECISION](OPERATIONS_DECISION.md)の1〜10とCSV/JSON要件を正式採用。定期収入、予算振分超過禁止、6項目＋その他、テンキー配列・ナビ維持、目標月履歴、80%/100%警告、JSON全量上書き、金額/返金、日本時間、2種類CSV、前月予算コピーと定期日補正を含む。
設定から家計簿の集計期間・締め日を変更可能。予算・収支・繰越は同じ期間で計算する。初期は1日〜末日、開始日は1〜28日、終了日は翌開始日前日。終了月で表示し実期間を併記、目標・CSVも同じ月名に対応。変更は現在期間の締め後から適用し、既存期間は維持。接続する端数は移行期間と明示し予算を手動設定、自動日割りなし。日付の重複・空白を禁止。定期周期拡張は追加承認していない。


## 承認済み追加要求 — 家族共有（2026-10-20）

[Issue #20](https://github.com/viaNEONIA/kakeibo/issues/20)のユーザー承認に基づき、家族で同一家計簿を親1台と子端末で共有。JSON手動交換を当面の方式とし、クラウド交換は将来項目とする。親が子を登録し、並行する編集/削除は親優先、子同士は子登録順を優先。因果的な後続変更と未編集の古いコピーは競合から区別し、競合採否と理由を表示する。月締め/再締め/精算確定は親専用。締め後取込は親で確認後に差額精算。別家計簿の合算は対象外。
詳細と未確定/実装制限は[FAMILY_SHARING](FAMILY_SHARING.md)を参照。親の引継ぎや月締め以外の管理権限の詳細を今回の承認から推測して確定しない。
