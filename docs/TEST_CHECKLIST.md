## 実施・記録方法

- 新機能だけ先に確認する場合は **G（目標）→ R（定期）→ C（CSV）**。全体受入ではU・B・F・Pも実施します。グループ間で試験データを混ぜず、前提を確認してください。
- 架空データ用の独立したブラウザー環境または専用端末を使用します。日常の家計簿を試験値で編集しません。サイトデータ削除・既存アプリのアンインストールを試験前提にしません。
- 親・子は別の保存環境を用意し、子ごとに別参加ファイルを発行します。親復旧の確認は元の試験親を停止してから行います。
- 結果は `未実施 / 合格 / 不合格 / 該当なし`。結果欄には環境IDも記入します。該当なしは理由を記載し、必須項目の免除を意味しません。
- 不合格時はID・版・手順・期待/実際・架空データの証跡を記録します。データ消失や計算不整合があれば、その状態とバックアップを保持し、関連試験を中断します。
