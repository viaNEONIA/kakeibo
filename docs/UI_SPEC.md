# UI仕様 v1.3

## 共通
412dp基準のレスポンシブ。下部固定ナビ: ホーム / 予算 / 入力 / 一覧 / 設定。主要画面はスクロール最小化。画面高さ不足時は操作可能性優先。タップ領域44〜48px目安。編集時は固定フッターに保存・閉じる。

## ホーム
当月収入、支出、基本予算、繰越からの配分、利用可能予算、残予算、項目別警告、直近定期支出予定を表示。予算警告は80%以上注意・100%で使い切り・100%超で超過とし、しきい値変更可能。収支と予算を混同しない。

## 予算
当月基本予算、項目別振分、未振分、繰越プール残高、当月への配分、目標額と達成率を表示。月別推移は詳細パネルに格納し、期間3/6/12か月・全期間を切替。月別追加・配分・調整・残高を確認可能。

## 入力
収入/支出切替、日付、金額、項目、名称/メモ（任意）、専用テンキー、登録ボタン。初期は支出。登録後は同じ画面で連続入力。直前登録の取消。頻出項目を優先表示、項目追加・並び替えは設定。名称履歴の候補は任意拡張。

## 収支一覧
1件1行。日付・名称/項目・金額を高密度表示。収入/支出、期間、項目、金額帯、名称、定期支出でフィルター。表示列と並び順を切替。行タップで編集・削除。件数が多いため一覧領域はスクロール可。

## 設定
項目管理、定期収支設定、通知閾値、入力設定、一覧表示設定、CSV出力、JSONバックアップ/復元、データ削除、アプリ情報。頻度の低い項目は折りたたみ。

## 未確定UI
端末高さ別の最終配置と任意拡張の履歴候補優先度は実機検証で決定。6項目＋その他・設定順、テンキー上段7/8/9・0/00/削除/クリア、独立登録ボタン、下部ナビ維持は承認済み。

## 承認済み繰越操作 — 2026-10-19

予算画面に月締め見込み・手動確定・再確定時の差額を表示する。実残高はマイナスも表示し警告、不足中は新規配分を停止。月別推移は正の追加と超過精算を区別する。初期プール残高は入力可能、初期値0円。過去修正時は後続月の再計算結果を反映し履歴を保持する。
実残高に「配分可能額」「未精算額」を併記する。未精算額は負残高の絶対値とし、後月の余剰で減少・解消する。[CARRYOVER_DECISION](CARRYOVER_DECISION.md)のQ-HOLDは承認済み。目標不足額とプール未精算額を混同しない。

## 承認済み運用設定

[OPERATIONS_DECISION](OPERATIONS_DECISION.md)に従い、定期収入・支出、目標適用開始月/変更履歴、目標解除、JSON全量上書き前確認・バックアップ案内、収支/プールの別CSVを提供。項目別予算の超過振分は保存せずエラー表示し、実績支出の超過登録は妨げない。設定に集計期間・締め日を追加し、現在の期間範囲を判別可能にする。期間選択肢・適用開始・移行確認はP-Q01/P-Q02の決定待ち。
