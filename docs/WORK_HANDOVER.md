# ChatGPT Work 初回移行指示書

## 目的
簡易家計簿PWA正式仕様v1.3をGitHub正本で継続開発できる状態へ移行する。

## 今回の作業範囲
1. 本リポジトリのREADME、SPEC、UI_SPEC、DATA_MODEL、ARCHITECTURE、TEST_PLAN、ROADMAP、OPEN_QUESTIONS、CHANGELOGを精査。
2. v1.0〜v1.3の確定仕様・推奨初期値・未確定事項・将来機能を区別。
3. 繰越プールの月末追加、当月配分、未使用分の再繰越、過去月修正について計算例を作り、二重計上・負残高リスクをレビュー。
4. 不明点と仕様矛盾を優先度付きで報告。承認を要する判断を明示。
5. 開発用Issue案（受入条件付き）と推奨ブランチ運用を作成。
6. GitHubへ登録・更新する場合は対象リポジトリと変更差分を確認する。

## 禁止事項
- 初回移行作業ではアプリ本体の実装・機能変更・リファクタリングを行わない。
- 未確定事項を独断で確定仕様にしない。
- 将来機能「目標達成予定月の推定」を実装しない。
- GitHub既存ファイルを確認なしに上書き・削除しない。

## 完了報告
ファイル一覧、確認済み仕様、矛盾・未確定事項、Issue案、次工程への移行可否を提示する。
